# SmartShot

Smart screenshots for macOS: hover to highlight a window, toolbar or page
content, click to capture — or drag, and the corners snap to real UI
edges. Built in Rust.

## Install

Open **Terminal** (⌘ Space → "Terminal") and paste:

```bash
curl -fsSL https://github.com/BilagoNet/smartshot/releases/latest/download/install.sh | bash
```

This downloads the latest version, checks it, puts SmartShot in
Applications and starts it — no "Apple could not verify" dialog. Run the
same line again to update.

Then allow **Screen Recording** and **Accessibility** when macOS asks,
quit SmartShot from its menu-bar icon and open it once more.

| Shortcut | Action |
|---|---|
| ⇧⌘2 | capture (click a highlighted region, or drag) |
| ⇧⌘1 | copy text from the screen |
| ⌥⇧⌘2 | repeat the last region |

Requires macOS 13 or newer (Apple Silicon or Intel).

Prefer a disk image? Download `SmartShot.dmg` from
[Releases](https://github.com/BilagoNet/smartshot/releases/latest) — the
first launch then needs System Settings → Privacy & Security → *Open Anyway*.

## O'rnatish

**Terminal**ni oching (⌘ + Space → "Terminal") va shu qatorni qo'ying:

```bash
curl -fsSL https://github.com/BilagoNet/smartshot/releases/latest/download/install.sh | bash
```

SmartShot yuklanadi, tekshiriladi, Applications'ga o'rnatiladi va ochiladi —
"Apple could not verify" oynasi chiqmaydi. Yangilash uchun ham shu qator.

So'ng **Screen Recording** va **Accessibility** ruxsatlarini bering, menyu
satridagi SmartShot belgisidan Quit qilib, yana bir marta oching.
Skrinshot: ⇧⌘2.
